# Code of conduct

Keep discussions constructive. Disagreement is useful when it stays focused on the work. Harassment, threats, personal attacks and discrimination aren't acceptable in issues, pull requests or other project spaces.

Describe problems clearly, make room for differing experience levels and explain technical tradeoffs without belittling people. Maintainers may edit or remove abusive comments and restrict participation when needed.

If you encounter abusive conduct, contact a maintainer privately through an available contact channel on their GitHub profile. You can also use GitHub's reporting controls. Don't disclose someone's private information in a public issue.
