# Security

The npm installer writes into a project's skill directory or an explicitly requested global directory. It should not run downloaded scripts, execute code from the installed skill, or overwrite existing files by default.

If you find a vulnerability, use GitHub's private vulnerability reporting for this repository once it is enabled. If private reporting is not available, open an issue requesting a private contact method without publishing exploit details.

Supported release line: current published version, once the first release exists. No npm release has been made as part of this starter package.
